### Win11 Installation - Initial setup
Remove Onedrive linking during Windows setup
Install Windows Pacakge Manager - Chocolatey

### Install following apps (via Chocolatey): 
**Image Backup**: macrium reflect free (backup image app)(last free version = 8.0.7783), take image backup in external harddisk or pendrive. Then take weekly/monthly differential image backups.

### After the initial  image backup, install the below tools (also via Choco):
**Browser**: 
- Chrome
**Tweaks**: 
- NoLockScreen registry editor:  
**Utilities**:
- Syncthing: sync folders/ drives between two or more devices via common wifi (free)
- Search everything
- flow-launcher: windows equivalent of Alfred in Mac
- Dropbox?
**PDF tools (free)**: Sumatra, PDF Gear, PDF24 creator
**Academics tools**: 
- Zotero
- Obsidian
- Capacities.io (block based note-taking tool)(online database with sync)
- Mogan Research (fork of Texmacs but updated regularly)(Latex like scientific writing tool)(Alternative to Lyx, but much better)(WYSIWYG editor)(can be exported to Latex/ PDF)
